# vivics

這是一個具備多模板、多版本管理的履歷編輯器。前端使用純 HTML/CSS/JS，後端使用 PHP + MySQL 儲存履歷版本、樣式與頭像。

## 系統功能說明

此系統提供可視化履歷編輯與多版本管理，核心功能如下：

- **多模板與多樣化風格**：可切換多種模板版型（教師風格、極簡、現代專業、創意、高階主管、科技感、寧靜雅緻），並提供多組色彩主題快速套用，打造不同視覺風格。
- **即時編輯與自動保存**：開啟編輯模式即可直接修改內容，系統會在輸入時自動保存至本機，並支援手動保存。
- **履歷與版本管理**：支援建立多份履歷、切換不同版本、另存版本與刪除版本，方便管理不同投遞情境。
- **樣式與字體設定**：可調整主色/輔色/背景色、字體大小與字體風格，並可保存成樣式預設以便快速套用。
- **圖片與頭像管理**：支援上傳頭像與插入圖片，強化履歷內容呈現。
- **列印與 PDF 預覽**：提供列印預覽模式，方便匯出 A4 PDF。
- **離線模式**：後端不可用時，仍可使用 localStorage 進行本機保存。

## 使用教學（功能詳解）

### 1. 模板切換與版型內容
1. 在工具列選擇「模板」下拉選單。
2. 點選想要的版型（教師風格、極簡、現代專業、創意、高階主管、科技感、寧靜雅緻）。
3. 模板會立即切換，原本的內容仍會以本機保存的版本為主。

### 2. 編輯模式與內容修改
1. 按下「編輯模式」按鈕，啟用可編輯狀態。
2. 直接點擊履歷內容即可修改文字。
3. 編輯時系統會自動保存到本機，並提示保存狀態。
4. 若要鎖定內容或準備列印，可再次點擊「編輯模式」關閉。

### 3. 新增/刪除內容模塊
1. 點擊「新增內容模塊」新增一個預設區塊。
2. 進入編輯模式後可修改標題與內容。
3. 若要移除，點擊區塊右上角的「刪除」即可移除該區塊。

### 4. 履歷與版本管理
**新增履歷**
1. 點擊「新增履歷」，輸入履歷名稱。
2. 系統會建立新的履歷記錄並可保存不同版本。

**切換履歷**
1. 在「履歷」下拉選單選擇想要的履歷。
2. 系統會自動載入該履歷的最新版本。

**另存版本**
1. 點擊「另存新版本」。
2. 輸入版本名稱，即可保存為新版本。

**刪除版本**
1. 點擊「刪除版本」。
2. 確認後即可移除該版本（不可復原）。

**刪除履歷**
1. 點擊「刪除履歷」。
2. 確認後會刪除該履歷及其所有版本與樣式預設。

### 5. 樣式與字體設定
1. 調整「主色、輔色、背景」色票，可即時變更外觀。
2. 在「字體大小 / 字體風格」選單中選擇適合的字體設定。
3. 點擊「保存樣式」可保存目前設定，便於之後快速套用。

### 6. 色彩主題快速套用
1. 在「風格主題」區塊點選不同色彩按鈕。
2. 系統會立即套用新的配色並自動保存。

### 7. 頭像與圖片插入
**設定頭像**
1. 點擊「設定頭像」並選擇圖片。
2. 系統會將頭像套用到模板中的頭像區塊。

**插入圖片**
1. 點擊「插入圖片」並選擇圖片。
2. 圖片會插入到當前游標位置或內容區塊底部。

### 8. 列印預覽與 PDF 匯出
1. 點擊「切換打印預覽模式」。
2. 使用 `Ctrl+P` / `Cmd+P` 開啟列印面板。
3. 選擇「另存為 PDF」即可匯出。

### 9. 離線模式與本機保存
1. 若後端不可用，系統會自動切換為離線模式。
2. 所有編輯內容仍會保存到瀏覽器的 localStorage。

## 功能概要

- 多模板切換（教師風格／極簡風格）
- 多履歷、多版本保存與切換
- 樣式（主色、輔色、背景、字體）預設保存與套用
- 離線模式仍可使用 localStorage 保存

## 後端啟動前準備

1. 建立資料庫與資料表：

```bash
mysql -u root -p -e "CREATE DATABASE resume_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p resume_app < db/schema.sql
```

2. 設定資料庫連線參數（直接編輯 `api/config.php`）：

3. 啟動 PHP 內建伺服器：

```bash
php -S 0.0.0.0:8000
```

然後在瀏覽器開啟 `http://localhost:8000/index.html`。

## API 檔案

- `api.php`：後端 API 入口

- `api/bootstrap.php`：PDO 連線與共用工具
- `db/schema.sql`：資料庫 schema 定義
